1. 修改前读取模块文档、对应布局图和已审阅基准；实际打开图片，记录资产 ID、阅读方式与关键观察。

3. 对照目标设计和基准列出差异，区分预期改变、缺陷与待确认项，按用户任务影响排序。
4. 修正缺陷后重新采集并复核受影响场景；保留修改前后证据和实际命令/人工步骤。
5. 经审阅后更新基准、模块文档和索引；不自动批准新的截图覆盖旧基准。

需要自动截图比较时按项目已有测试能力接入，比较环境、动态区域、容差及理由登记在 [04](04-test-map.md)。自动差异只能说明相对基准的变化，基准本身仍需设计审阅。

## ⚠️ 已知限制

由于后端需要认证：
- ⚠️ 提交作业会返回 401 错误（需要 token）
- ⚠️ 作业列表会返回 401 错误（需要 token）
- ⚠️ 候选库会返回 401 错误（需要 token）

**这是正常的！** 说明后端 API 正确实现了认证机制。

要完整测试，需要：
1. 创建测试用户
2. 生成 JWT token
3. 在浏览器 localStorage 设置 token
